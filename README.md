# Jarvis Web (نسخه‌ی وب/اپ نصبی برای گوشی)

بدون ساخت APK، بدون Buildozer. فقط ۵ فایل.
کلید API داخل فایل‌ها نیست؛ بعد از باز کردن، از دکمه‌ی SET وارد کنید (فقط روی همان گوشی ذخیره می‌شود).

## راه اول: GitHub Pages (پیشنهادی؛ میکروفون هم کار می‌کند)
1. در GitHub یک مخزن **جدید و Public** بسازید (مثلاً jarvis-web). (Pages برای مخزن Private رایگان نیست.)
2. هر ۵ فایل را در ریشه‌ی مخزن آپلود و Commit کنید: index.html، manifest.json، sw.js، icon-192.png، icon-512.png
3. مخزن → Settings → Pages → Source: Deploy from a branch → Branch: main، پوشه‌ی / (root) → Save
4. بعد از ۱ تا ۲ دقیقه، آدرس https://USERNAME.github.io/jarvis-web/ ساخته می‌شود.
5. آن را در Chrome گوشی باز کنید → منوی ⋮ → Install app (یا Add to Home screen).

## راه دوم (فقط تست سریع)
فایل index.html را به گوشی بفرستید و با Chrome باز کنید. چت کار می‌کند، ولی میکروفون معمولاً فقط روی https کار می‌کند.

## تبدیل به APK واقعی (اختیاری، بعد از راه اول)
در pwabuilder.com آدرس سایت را بدهید → Package for stores → Android → دانلود.

## محدودیت‌ها
- باز کردن برنامه فقط برای برنامه‌هایی که لینک مستقیم دارند: تلگرام، واتساپ، اینستاگرام، یوتیوب، اسپاتیفای، ایمیل، دیسکورد، نقشه، شماره‌گیر و پیامک. برای باز کردن لینک، دکمه‌ی «↗» زیر پاسخ را بزنید.
- باز کردن فایل و پوشه‌ی گوشی ممکن نیست.
- صدای فارسی فقط وقتی کار می‌کند که گوشی موتور Text-to-speech فارسی داشته باشد.
